# OOP Lab Practicals

This repository contains Java programs for all listed OOP lab practicals.

## Practicals

1. Time conversion (HH:MM:SS)
2. Odd-even array rearrangement
3. Same rightmost digit checker
4. Complex number operations
5. Address/Student/Employee constructor passing
6. Abstract Shape class with inheritance
7. Exception Handling GUI division program
8. Multithreading random number program
9. Student Record Management using File Handling
10. Doubly Linked List operations
11. Traffic Light simulation
12. Quick Sort implementation
